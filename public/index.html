    If !addcmd doesn't work

    Add each command in the Fossabot dashboard instead (Commands → Add command): use the command name on the left and the $(customapi …) part as the response. Set the mod commands to "Moderator" permission there too. Movie Clock also checks mod status itself, so a wrong setting can't let viewers run them.
